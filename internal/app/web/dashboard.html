1. Configure this computer

Choose Host on the first PC. Choose Join on the second PC.

Paste a folder path from File Explorer. The folder is created if needed. Subfolders and files sync; empty directories are not replicated. Use .gitignore or .folderbridgeignore in this folder to exclude files.

2. Pair the second computer

Run the same app on your second PC, choose Join, paste one of these links, and select its local folder. Keep pairing links private.

If several network addresses are shown, use the one reachable from your second PC. Host PC must be online. Windows Firewall may require an authorized inbound rule for TCP 48713.

Windows integration

Starts minimized to the system tray for this Windows user only. No administrator rights required. Right-click the tray icon to open the dashboard, open the folder, pause, or quit.
